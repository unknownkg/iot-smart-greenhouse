# IoT Smart Greenhouse

Учебная SCADA/IoT-панель на HTML5, CSS3 и нативном JavaScript. Реальное оборудование не подключено; показания и устройства являются программной демонстрацией.

Публичная история подготовлена из последовательных реальных этапов локального проекта с очисткой приватных данных. Это новые коммиты публичной редакции; исходная история сохранена отдельно. [Происхождение и соответствие этапов](docs/history.md).

## Состояние этого исторического снимка

Исходный этап: **Аналитика и графики** (`29bbd52`). Возможности накапливаются в следующем порядке:

- Восемь страниц с общей навигацией, адаптивным боковым меню и демонстрационными карточками. Симуляция, хранение и управление ещё не реализованы.
- Уточнены стили панели, карточек и компоновка. Функциональные возможности соответствуют каркасу приложения.
- Добавлены общая модель трёх зон и 18 датчиков, проверка состояния и сохранение в localStorage. Симулятор на этом этапе ещё отсутствует.
- Добавлены постепенные изменения 18 виртуальных датчиков, пауза, продолжение, один шаг и ограниченная история измерений. Показания обновляют обзор, зоны и реестр датчиков.
- Добавлены ручные команды для 18 виртуальных устройств, влияние устройств на учебные показания, блокировка насоса при недостатке воды и защитные ограничения конфликтующих команд.
- Добавлены автоматические правила по зонам, ручной и автоматический режимы, редактирование порогов, гистерезис и семь воспроизводимых учебных сценариев.
- Добавлены жизненный цикл предупреждений, журнал реальных команд и переходов, фильтры, ограничение накопленных записей и сохранение событий.
- Добавлены пять графиков Chart.js, объяснимый индекс риска, поиск отклонений и рекомендации. Аналитика использует данные общего состояния и не управляет устройствами.

## Локальный запуск на Windows

Откройте PowerShell в папке проекта рядом с `index.html`. При установленном Python 3 выполните:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8080/](http://127.0.0.1:8080/). Остановка сервера — Ctrl+C. Если порт занят, используйте сервер этого проекта или свободный порт. Сервер только раздаёт файлы; backend и сборка не нужны. Для ES-модулей используйте HTTP, а не `file://`.

## Автоматические проверки

Для запуска имеющихся в этом снимке тестов нужен Node.js с поддержкой `node:test`:

```powershell
node --test tests/*.test.mjs
```

Результаты прежних сессий не выдаются за новый прогон этой публичной копии. Итоговая проверка выполняется после переноса готовой версии.
