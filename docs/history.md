# Происхождение публичной истории

Публичная история подготовлена из 11 последовательных реальных этапов локального проекта после очистки приватных данных и внутренних рабочих материалов. Это новая публичная редакция истории, а не неизменённая первоначальная история разработки. Исходный локальный репозиторий и его резервная копия сохранены отдельно.

Каждый публичный коммит соответствует следующему исходному снимку. Файлы приложения, тесты и сторонняя библиотека с лицензиями перенесены без изменения байтов; редакционная подготовка затрагивает README, состав документации и правила исключения локальных материалов.

Хеши в таблице обозначают исходные локальные коммиты и не являются хешами публичного репозитория. Новые коммиты создаются при подготовке публичной редакции с текущими датами Git; даты, подписи и иные метаданные первоначальных коммитов не копируются. Сами этапы и их порядок взяты из существующей истории, а не придуманы для заполнения списка коммитов.

Промежуточные README описывают возможности соответствующих исторических снимков. Инструкция и результаты проверок готовой версии находятся в [текущем README](../README.md). Внутренние рабочие планы, диагностические протоколы и полный архив контрольных снимков в публичную редакцию не входят. Сохранены три выбранные настоящие иллюстрации и техническое руководство готового проекта.

Подготовка этой локальной редакции не означает публикацию на GitHub или включение GitHub Pages.
